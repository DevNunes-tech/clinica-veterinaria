# Clínica Veterinária — Projeto Desenvolvimento Web

Este repositório contém um site institucional para uma clínica veterinária, desenvolvido como prática de **Desenvolvimento Web** com foco em HTML, CSS e JavaScript.

A estrutura e a proposta visual foram inspiradas no exemplo do professor do projeto referência, com ajustes para a marca do projeto e com a inclusão de interações dinâmicas no formulário e no chatbot.

---

## 📌 Sobre o Projeto

O objetivo do projeto é apresentar uma clínica veterinária de forma moderna e funcional, incluindo:

- banner principal com chamada visual;
- seção sobre a clínica;
- cards de serviços;
- formulário de contato com validação simples;
- chatbot de atendimento com respostas automáticas.

---

## ✅ Funcionalidades Implementadas

- layout institucional em HTML e CSS responsivo;
- menu de navegação interno;
- hero section com imagem de fundo;
- cards de serviços;
- formulário de agendamento com validação em JavaScript;
- botão flutuante de atendimento com widget de chat;
- mensagens automáticas no chatbot com base em palavras-chave.

## ▶️ Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/DevNunes-tech/clinica-veterinaria.git
```

2. Acesse a pasta do projeto:

```bash
cd clinica-veterinaria
```

3. Abra o arquivo abaixo em um navegador:

```bash
/dashboard/index.html
```

> Também é possível abrir o arquivo pelo VS Code com a extensão Live Server para uma melhor experiência de desenvolvimento.
